Zilliqa EVM is Zilliqa's only production side: you use a standard `0x...` address with any EVM-compatible wallet like MetaMask, Rabby, or WalletConnect-enabled wallets. Scilla contracts are retired, but existing Scilla-native ZRC-2 tokens remain usable from EVM through allow-listed ERC-20 proxy contracts. This guide explains how those proxies work, how they differ from regular ERC-20 tokens, and which proxy addresses to use.

> Note: Legacy `zil1` addresses are no longer used - use your `0x` EVM address. If you have funds in a legacy wallet, follow Zilliqa's [official guidance](https://www.zilliqa.com/ledger-incident/).

## Using Scilla-Native ZRC-2 Tokens on EVM

Scilla-native tokens (ZRC-2) are the only remaining bridge to Scilla: they are used from EVM through allow-listed ERC-20 proxy contracts.

1. The token is represented on EVM through a specific **proxy contract** (`0x...` address).
2. Add the proxy address as a custom token in your EVM wallet to see your balance and interact with EVM dApps.

### Proxy Behaviour Developers Must Know

ZRC-2 proxies look like ERC-20 tokens, but they behave differently:

- `balanceOf`, `transfer` and `approve` act on the **underlying Scilla token**.
- The proxy emits **no** ERC-20 `Transfer` or `Approval` events, so event-based indexers and UIs won't see these movements.
- A failed transfer **reverts the entire transaction** - it can't be caught with `try/catch`.
- Amounts are capped at `uint128`, so `approve(type(uint256).max)` reverts.
- `decimals` varies per token (e.g. gZIL uses 15, zUSDT uses 6) - always read it instead of assuming 18.
- Only **allow-listed** proxies work; newly deployed proxies fail.

## Adding ZRC-2 Proxy Tokens to Your Wallet

1. Find the EVM proxy contract address for your token in the tables below.
2. In your EVM wallet (MetaMask, Rabby, etc.), select "Add token" or "Import token."
3. Paste the proxy `0x...` address. The wallet auto-populates token details.
4. Confirm to see your balance and use with EVM dApps.

> Important: Only use proxy addresses that you trust. Unvetted proxies may not represent real assets, and proxies that aren't allow-listed won't work.

## Critical Warnings

- Use your `0x...` EVM address for all transactions.
- Only use the vetted proxy addresses listed above; proxies that aren't allow-listed won't work.
- Confirm token type (ZIL, ZRC-2, ERC-20), the destination `0x...` address, and fees before sending.

## Wallet Options

### EVM Wallets (MetaMask, Rabby, WalletConnect)

Standard EVM wallets like MetaMask, Rabby, or any WalletConnect-enabled wallet can be used for Zilliqa EVM:
- Simply add the Zilliqa EVM network to your wallet configuration.
- These wallets use your `0x...` EVM address.
- To use ZRC-2 tokens, add their proxy contract as a custom token (see above).
